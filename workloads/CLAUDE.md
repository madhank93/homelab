# workloads/ — CDK8s (Go)

- Every app is one entry in the `apps` table in `main.go`; it synthesizes to `app/<dir>`, which Argo CD deploys as one Application.
- Never render a new `Secret`. Secrets come from OpenBao through the Secrets Store CSI driver; `scripts/manifest-secret-guard.sh` fails on any Secret not in `scripts/manifest-secret-allowlist.txt`, and that list may only shrink.
- `imports/` is generated by `cdk8s import` from versions in `cdk8s.yaml`; regenerate, never hand-edit.
- Verify a refactor by diffing `app/` before and after `just synth`. The only expected noise is chart-generated random values in `harbor/` and `victoria-metrics/` (secrets, certs, their checksum annotations); any other diff is a behaviour change.
- Images carry an explicit tag or digest; routes attach to the shared Gateway from `config/config.yml`.

Procedures: `homelab-cdk8s` skill.
