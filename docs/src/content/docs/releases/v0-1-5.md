## Highlights

- **OpenBao replaces Infisical.** OpenBao plus the Secrets Store CSI Driver, unsealed by a sidecar. Pattern A (file only) for Grafana; Pattern B (synced Secret) for Harbor, n8n and NetBird.
- **n8n** on the 8gears chart with a CloudNativePG `n8n-pg` cluster instead of Bitnami PostgreSQL.
- **HTTPRoute drift.** Explicit `group`/`kind` on `parentRefs` and `backendRefs` stopped permanent Argo CD diffs.
- **Harbor** HTTPRoute points at `harbor:80` (nginx), not `harbor-core:80`.
- **GPU validator** init containers removed so the device plugin advertises the Blackwell GPU on Talos.

## Manual steps

1. `just openbao-init`, store the unseal key in SOPS, `just create-secrets`, then `just openbao-setup`.
2. Delete the old n8n Deployment (`kubectl delete deployment n8n -n n8n`): its selector is immutable across the chart change.
3. Force-delete pods stuck holding RWO volumes during the Harbor rollout.
