Released 2026-05-29. Full notes: [`v0.1.6-RELEASE-NOTES.md`](src:docs/releases/v0.1.6-RELEASE-NOTES.md).

## Highlights

- **Platform.** Talos 1.12.4 → 1.13.3; Cilium 1.16.6 → 1.19.4 in steps; Argo CD chart 9.5.15.
- **Bifrost.** Traefik 3.7, NetBird pinned at 0.71.4 on every component, Authentik 2026.5.2 (security fix), Gatus at `uptime.madhan.app`.
- **Workloads.** Every chart bumped; CDK8s Kubernetes API target 1.30 → 1.35 and imports regenerated.
- **Removed Rancher and Fleet.** Argo CD and Headlamp cover management.
- **Fixes.** Trivy node-collector no longer mounts systemd paths missing on Talos; OTel duplicate `K8S_NODE_IP` removed; NetBird peer no longer pinned to worker1; Cilium `devices` lists both `eth0` and `ens18` after Talos renamed the NIC.

## Manual steps

1. Upgrade Cilium one minor at a time (1.16 → 1.17 → 1.18 → 1.19); do not jump with a single `just core platform up`.
2. Apply Bifrost with `just core hetzner up`.
