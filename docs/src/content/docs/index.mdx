## One command per layer

```bash frame="terminal" title="From bare Proxmox to synced cluster"
just create-secrets      # bootstrap Secrets from SOPS
just core talos up       # VMs + Talos cluster
just core platform up    # Cilium, cert-manager, Argo CD
just core hetzner up     # Bifrost edge: Traefik, NetBird, Authentik
```

Argo CD takes it from there. The [deploy guide](/start/deploy/) walks every phase.
