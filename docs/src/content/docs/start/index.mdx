## Principles

| Rule | What it means here |
|---|---|
| Everything as code | Pulumi in `core/`, CDK8s in `workloads/`, shared values in `config/config.yml`. |
| No manual cluster changes | `kubectl edit` and `kubectl scale` are reverted by Argo CD self-heal; change git instead. |
| No plaintext secrets in git | Bootstrap secrets are SOPS-encrypted; runtime secrets live in OpenBao. CDK8s renders no Secret objects. |
| Zero-touch automation | `just` recipes drive every phase; the only manual steps are in third-party UIs (NetBird). |
