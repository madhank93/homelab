Goal: OpenBao unsealed and auto-unsealing, with a policy, a role and seeded secrets for every app. About 10 minutes.

## Procedure

<Steps>

1. Wait for the OpenBao pod to run. It stays sealed.

   ```sh frame="terminal"
   kubectl get pods -n openbao -w
   ```

2. Initialise and unseal. The recipe revokes the init root token at once and writes only the unseal key, to `~/openbao-unseal-key` (mode 600).

   ```sh frame="terminal"
   just openbao-init
   ```

3. Set `OPENBAO_UNSEAL_KEY` in SOPS to the contents of that file.

   ```sh frame="terminal"
   just sops-view secrets/bootstrap.sops.yaml
   ```

4. Push the real key into the cluster and restart the pod. The StatefulSet uses `OnDelete`, so a rollout does nothing; the unseal sidecar reads the new Secret on start.

   ```sh frame="terminal"
   just create-secrets
   kubectl delete pod -n openbao openbao-0
   rm ~/openbao-unseal-key
   ```

5. Enable Kubernetes auth and KV v2, write a read-only policy and role per app, and seed every missing key.

   ```sh frame="terminal"
   just openbao-setup
   ```

</Steps>

`openbao-setup` is idempotent: it rewrites auth, policies and roles, but never overwrites a key that exists. The OAuth client secrets come from SOPS: `GRAFANA_OAUTH_CLIENT_SECRET` → `secret/grafana`, `HARBOR_OAUTH_CLIENT_SECRET` → `secret/harbor`, `HOMEPAGE_OAUTH_CLIENT_SECRET` → `secret/homepage` and `KUBERNETES_OAUTH_CLIENT_SECRET` → `secret/headlamp`. Everything else is random. `NETBIRD_SETUP_KEY` starts as a placeholder so the CSI mount succeeds, and gets its real value in [Phase 6](/start/deploy/6-netbird-keys/).

:::caution[openbao-init refuses to run twice]
It stops if `~/openbao-unseal-key` exists. Move the key into SOPS and delete the file first.
:::

:::caution[openbao-setup stops on a missing SOPS key]
It exits if any of `GRAFANA_OAUTH_CLIENT_SECRET`, `HARBOR_OAUTH_CLIENT_SECRET`, `HOMEPAGE_OAUTH_CLIENT_SECRET` or `KUBERNETES_OAUTH_CLIENT_SECRET` is missing from the SOPS file. Add it (see [Phase 0](/start/deploy/0-prerequisites/)) and re-run.
:::

## Check

```sh frame="terminal"
kubectl exec -n openbao openbao-0 -c openbao -- bao status | grep Sealed
just openbao-sa-get grafana grafana grafana secret/grafana ADMIN_PASSWORD >/dev/null && echo policy-ok
kubectl get applications -n argocd
```

`Sealed false`, then `policy-ok`. Apps turn `Healthy` as their CSI volumes mount.
