Two Pulumi stacks build the cluster and its base services; from then on Argo CD deploys everything else from CDK8s output. Both stacks run from the laptop.

| Stack | Command | Manages |
|---|---|---|
| `talos` | `just core talos up` | Proxmox VMs, Talos machine configs, etcd bootstrap |
| `platform` | `just core platform up` | Gateway API CRDs, Cilium, the shared Gateway, cert-manager, Argo CD |
