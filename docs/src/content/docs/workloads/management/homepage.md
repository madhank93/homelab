Homepage is the start page: one tile per app with its live status, plus cluster and node usage. [Upstream docs](https://gethomepage.dev/).

| | |
|---|---|
| Namespace | `homepage` |
| Source | [`homepage.go`](src:workloads/management/homepage.go), config in [`homepage/`](src:workloads/management/homepage/) |
| Exposure | LAN · `home.madhan.app` |
| Login | Authentik OIDC, `grafana-admins` group only |

## Editing the page

Tiles live in `homepage/services.yaml`, the top bar in `widgets.yaml`, and layout in `settings.yaml` ([config reference](https://gethomepage.dev/configs/services/)). Every file in that directory becomes a key of the `homepage` ConfigMap; Reloader restarts the pod when it changes.

Icons are [dashboard-icons](https://dashboardicons.com) names (`grafana.svg`); apps without one use `mdi-` or `si-` icons. `{{HOMEPAGE_VAR_DOMAIN}}` is filled from `domain` in `config.yml`. Each tile's status dot comes from `siteMonitor`, which Homepage checks from inside the cluster.

## Login

Homepage's own auth gate signs in through the Authentik `homepage` OIDC app ([`authentik.go`](src:core/cloud/authentik.go)). Homepage admits anyone Authentik authorizes, and any GitHub account can enroll in Authentik, so a policy binding limits the app to `grafana-admins` (users from `grafana_admins` in `config.yml`).

| Secret | Source |
|---|---|
| `OAUTH_CLIENT_SECRET` | SOPS `HOMEPAGE_OAUTH_CLIENT_SECRET`, seeded into OpenBao `secret/homepage` |
| `AUTH_SECRET` | Random, generated by `just openbao-setup` (session cookie key) |

If the OIDC login breaks, `https://home.madhan.app/auth/signin?autologin=0` shows the login page without redirecting.
