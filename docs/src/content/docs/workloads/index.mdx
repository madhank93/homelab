Each app is a CDK8s chart in [`main.go`](src:workloads/main.go), synthesized by CI and synced by Argo CD from the manifests branch named in [`config.yml`](src:config/config.yml). Runtime secrets come from OpenBao; see [Secrets](/concepts/secrets/).

| [Notebook gateway controller](/workloads/ai/notebook-gateway-controller/) | AI | none | Adds notebook paths to `kubeflow.madhan.app` | — |
| [NVIDIA device plugin](/workloads/hardware/nvidia-device-plugin/) | Hardware | none | — | — |

| [Open WebUI](/workloads/ai/open-webui/) | AI | LAN | `chat.madhan.app` | Own login |

| [Argo CD monitor](/workloads/observability/argocd-monitor/) | Observability | none | — | — |

| [Metrics Server](/workloads/monitoring/metrics-server/) | Monitoring | none | — | — |
| [OpenTelemetry](/workloads/observability/opentelemetry/) | Observability | none | — | — |
| [VictoriaLogs](/workloads/observability/victoria-logs/) | Observability | LAN | `victorialogs.madhan.app` | None |
| [VictoriaMetrics](/workloads/observability/victoria-metrics/) | Observability | LAN | `vmselect.madhan.app`, `alertmanager.madhan.app` | None |

| [NetBird peer](/workloads/networking/netbird-peer/) | Networking | none (it is the VPN route) | — | — |

| [OpenBao](/workloads/secrets/openbao/) | Secrets | LAN | `openbao.madhan.app` | OpenBao token |
| [Secrets Store CSI driver](/workloads/secrets/csi-driver/) | Secrets | none | — | — |

| [Trivy](/workloads/security/trivy/) | Security | none | — | — |

| [Reloader](/workloads/support/reloader/) | Support | none | — | — |

**Public** means listed in `publicServices` in [`cloudflare.go`](src:core/cloud/cloudflare.go), served through Bifrost. **LAN** means an HTTPRoute on the shared Gateway (or a LoadBalancer IP); NetBird VPN clients reach these too, through the routing peer. See [Exposure](/cloud/exposure/).

:::caution[LAN services have no login of their own]
Rows marked "None" trust anything that can reach the LAN or the VPN. Keep them out of `publicServices` unless Bifrost's Authentik ForwardAuth sits in front.
:::
