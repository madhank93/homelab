Three tools act at three moments; only Kyverno can block anything.

| Tool | Acts at | Does |
|---|---|---|
| Kyverno | Admission | Rejects or mutates resources (no policies yet) |
| Trivy | After admission | Scans running workloads for CVEs and misconfig |
| Falco | Runtime | Alerts on suspicious syscalls |
