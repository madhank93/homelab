Overview

A seven-node Talos Kubernetes cluster on one Proxmox host, with a Hetzner VPS as the public edge and an RTX 5070 Ti for AI workloads. Everything above the bare metal is declared in this repo and rebuilt from it.

Layers

Section titled “Layers”

Apps

Ollama, ComfyUI, Grafana, Harbor, n8n, Falco and the rest. Argo CD + CDK8s.

Platform

Talos, Cilium, Gateway API, cert-manager, Argo CD. Pulumi.

Infrastructure

Seven Proxmox VMs and the Bifrost VPS on Hetzner. Pulumi.

Hardware

The Proxmox host and its GPU. Manual.

Principles

Section titled “Principles”
RuleWhat it means here
Everything as codePulumi in core/, CDK8s in workloads/, shared values in config/config.yml.
No manual cluster changeskubectl edit and kubectl scale are reverted by Argo CD self-heal; change git instead.
No plaintext secrets in gitBootstrap secrets are SOPS-encrypted; runtime secrets live in OpenBao. CDK8s renders no Secret objects.
Zero-touch automationjust recipes drive every phase; the only manual steps are in third-party UIs (NetBird).
